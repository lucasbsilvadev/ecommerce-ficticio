Ecommerce fictício de clothing.

Trata-se de um front-end para e-commerce desenvolvido em React, integrado com Supabase e Typescript no backend.
No momento, o projeto está pausado, embora seja apenas voltado para o meio acadêmico, ele estava funcionando em prod.
Resolvi deixá-lo ocioso por um tempo para treinar novas linguagens no backend, e explorar mais o universo do backend já que o supabase "toma conta de tudo" muito facilmente.
Pretendo entender mais sobre arquitetura, implantação e hospedagem de backend + DB. Em breve, com testes automatizados, monitoramento e outros fundamentos, utilizando Docker.
